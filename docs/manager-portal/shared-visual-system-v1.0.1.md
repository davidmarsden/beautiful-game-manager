# Shared visual system v1.0.1

This patch release follows the first Manager Portal adoption of the shared TBG visual contract.

## Changes

- restores the Pink Final's pink, black and pale-blush palette as the Manager Portal foundation;
- keeps the portal's denser operational workspace hierarchy;
- prevents the first navigation item from overriding its active, hover or focus treatment;
- gives sticky mobile table cells opaque surfaces with explicit hover and selected states.

## Compatibility

The update changes presentation only. It does not alter world state, permissions, data projections, game rules or manager commands.
